## 🧠 Engineering Philosophy

> **Understand the abstraction. Then understand what happens underneath it.**

I believe strong engineers should be able to move between levels of abstraction:

```text
API
 ↓
Application
 ↓
Framework
 ↓
Runtime
 ↓
Operating System
 ↓
Network
 ↓
Storage
 ↓
Hardware
```

When production systems fail, the bug isn't always where the exception was thrown.
